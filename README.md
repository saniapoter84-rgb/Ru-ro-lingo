# RU → RO Lingo

Личное приложение для изучения румынского языка через русский (а не через английский, как в Duolingo).

## Что внутри

- **18 тематических юнитов**, ≈400 слов и фраз: приветствия, местоимения, числа, семья, еда, цвета, календарь, время, глаголы, дом, одежда, тело, город/транспорт, природа, профессии, прилагательные, вопросы, дорожные фразы.
- **Система интервального повторения (SRS)** — освоенные слова показываются всё реже, а забытые возвращаются быстро (`src/logic/srs.ts`).
- **Три типа упражнений**: выбор перевода RU→RO, выбор перевода RO→RU, ввод перевода текстом (с допуском ответа без диакритики — `ș/ț/ă/â/î`).
- **Стрик и очки опыта (XP)**, прогресс по каждой теме — экран «Мой прогресс».
- **Озвучка румынских слов** через `expo-speech` (голос `ro-RO`; доступность зависит от устройства).
- Весь прогресс хранится локально на устройстве (`AsyncStorage`) — сервер не нужен.

## Как запустить

```bash
npm install
npm start        # откроется Expo Dev Tools / QR-код
```

Дальше — по вкусу:

- `npm run android` — открыть в эмуляторе/на Android-устройстве (нужен Expo Go или dev-build)
- `npm run ios` — то же для iOS (нужен Mac)
- `npm run web` — быстрый предпросмотр в браузере (для проверки, не основная платформа)

Проще всего поставить приложение **Expo Go** на телефон и отсканировать QR-код из терминала — тогда не нужны Android Studio/Xcode.

## Структура проекта

```
src/
  data/         словарь по темам (units.ts) + сборка уроков (index.ts)
  logic/        SRS, прогресс/стрик/XP, генератор упражнений, озвучка, хранилище
  screens/      HomeScreen, LessonScreen, StatsScreen
  components/   переиспользуемые UI-кусочки (кнопка, прогресс-бар, кнопка озвучки)
  theme/        цвета
```

## Как расширять словарь

Добавляй новые юниты/слова прямо в `src/data/units.ts` — уроки (`ALL_LESSONS`) и id слов пересобираются автоматически из этого файла, ничего руками синхронизировать не нужно.

## Известные ограничения v1

- Нет звуковых файлов "из коробки" — озвучка идёт через системный TTS телефона; если на устройстве не установлен румынский голос, звук может не воспроизвестись.
- Иконка/сплэш-экран — стандартные, из шаблона Expo (можно заменить файлы в `assets/`).
- Нет облачной синхронизации прогресса между устройствами — всё хранится локально.
