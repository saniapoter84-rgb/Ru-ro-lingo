# RuRo Lingo

**Ru**ssian → **Ro**manian. Приложение для изучения румынского через русский — не через английский, как в Duolingo. Родной язык — русский, изучаемый — румынский, и вся подача построена именно на этой паре: правила объясняются через «в русском так, а тут вот так».

## Что внутри

### Тропа — курс грамматики с нуля

Основной режим. Семь глав от «нулевого» уровня до A2: **36 уроков, 337 заданий, 95 карточек правил, 7 боссов**.

| Глава | Тема | Уровень |
|---|---|---|
| 1. Я есть | глагол `a fi`, род, вопрос, отрицание | A0 |
| 2. Тот самый | артикль-суффикс, множественное число, числа + `de` | A0 |
| 3. Моё и твоё | `a avea`, притяжательные, прилагательные, сравнение | A1 |
| 4. Действие | четыре группы глаголов, неправильные, возвратные | A1 |
| 5. Где и куда | предлоги, исчезающий артикль, вопросительные слова | A1 |
| 6. Вчера и завтра | `perfect compus`, причастия, будущее `o să` | A2 |
| 7. Живая речь | конъюнктив вместо инфинитива, клитики, `pe`, вежливость | A2 |

Курс сделан контрастивно к русскому — упор на то, что для русскоговорящего неочевидно:

- определённый артикль приклеивается **к концу** слова (`casă → casa`);
- прилагательное стоит **после** существительного;
- притяжательное согласуется с **предметом**, а не с владельцем;
- после предлога артикль **пропадает** (`la magazin`, но `cu mașina`);
- перед одушевлённым дополнением ставится **`pe`** — и местоимение при этом удваивается;
- вместо инфинитива используется **`să` + спрягаемый глагол** (`Vreau să merg`);
- а двойное отрицание, наоборот, работает **как в русском** — редкий случай, когда можно переводить буквально.

Восемь типов заданий, чтобы урок не превращался в один и тот же клик: карточка правила, выбор варианта, сборка фразы из слов, ввод текста, сопоставление пар, аудирование, поиск ошибки в предложении, преобразование формы.

### Режим погружения

Переключатель, после которого приложение **целиком переходит на румынский**: интерфейс, кнопки, подписи, подбадривания. Переводы никуда не деваются, но прячутся под тап — их надо запросить осознанно.

Плюс 10 бытовых сцен с полным разбором: кафе, рынок, такси, аптека, соседка, касса вокзала, ресторан, собеседование, планы на выходные, знакомство. У каждой — реплики с озвучкой и построчным переводом по тапу, вопросы **на румынском** и список выражений на вынос.

### Словарь по темам

38 тематических юнитов, ≈1000 слов и фраз. Карточки со свайпом, три типа упражнений, интервальное повторение (SRS): освоенные слова показываются всё реже, забытые возвращаются быстро.

### Что заставляет возвращаться

- **Сердца** — пять штук, одно восстанавливается за 20 минут. У боссов запас всего три.
- **Комбо** — 3 правильных подряд дают ×2 опыта, 6 → ×3, 9 → ×4.
- **Задания дня** — три штуки, набор детерминирован датой и усложняется со временем.
- **Ачивки** — 20 штук, включая скрытые (позаниматься до девяти утра, после полуночи).
- **Ранги** — от «Новичка» до «Почти румына» по общему опыту.
- **Цель дня** и стрик по дням подряд.

## Как запустить

```bash
npm install
npm start          # Expo Dev Tools + QR-код
```

Дальше — `npm run android` / `npm run ios` / `npm run web`, либо просто отсканировать QR-код приложением **Expo Go** на телефоне.

### Собрать релизный APK

```bash
export ANDROID_HOME=/path/to/android-sdk
npx expo prebuild --platform android --clean
cd android && ./gradlew assembleRelease
# итог: android/app/build/outputs/apk/release/app-release.apk
```

Ключ подписи задаётся в `android/gradle.properties` (`RURO_UPLOAD_STORE_FILE` и рядом). Без них соберётся debug-вариант.

## Структура

```
src/
  data/
    units.ts, units2.ts   словарь по темам
    grammar.ts            справочник (списком, без заданий)
    course/               «Тропа»: types.ts + ch1…ch7 + index.ts
    dialogues.ts          сцены для погружения
  logic/
    courseEngine.ts       разбор шагов урока, сверка ответов, опыт и комбо
    progress.ts           всё состояние: слова, курс, сцены, ранги, сводки
    hearts.ts             сердца и их восстановление по времени
    quests.ts             ежедневные задания
    achievements.ts       ачивки
    srs.ts                интервальное повторение
    storage.ts            AsyncStorage + миграция v1 → v2
  screens/                Course, CourseLesson, Immersion, Dialogue, Profile, …
  components/             панели, кнопки, сердца, комбо, тосты
  i18n/strings.ts         интерфейс на двух языках (для погружения)
  theme/colors.ts         тёмная тема, отступы, скругления
```

## Как расширять

- **Слова** — дописывать в `src/data/units.ts`; уроки и id пересобираются автоматически.
- **Курс** — новая глава это новый файл `src/data/course/chN.ts`, добавленный в массив в `index.ts`. Порядок уроков в массиве = порядок открытия на карте.
- **Сцены погружения** — новый объект в `src/data/dialogues.ts`.

## Ограничения

- Озвучка идёт через системный TTS телефона (`expo-speech`, голос `ro-RO`). Если румынский голос на устройстве не установлен, звук может не воспроизвестись — это лечится установкой голоса в настройках Android/iOS.
- Прогресс хранится локально, облачной синхронизации между устройствами нет.
- Иконка и сплэш — из шаблона Expo, файлы в `assets/` можно заменить.
