# RuRo Lingo

**Ru**ssian → **Ro**manian. Приложение для изучения румынского через русский — не через английский, как в Duolingo. Родной язык русский, изучаемый румынский, и вся подача построена именно на этой паре: правила объясняются через «в русском так, а тут вот так».

## План: B1 за два месяца жизни

Главный экран — не список глав, а восьминедельный план. Ключевое слово в нём — **жизни**, а не «занятий»: норма разложена на **пять дней в неделю**, два дня заложены свободными заранее. Пропустить их значит выполнить план, а не сорвать его; кто занимался все семь — идёт с запасом.

| Неделя | Тема | Уровень | Грамматика |
|---|---|---|---|
| 1 | Ты уже говоришь | A0 | `a fi`, род, вопрос, отрицание, артикль-суффикс, множественное число |
| 2 | Моё и твоё | A1 | `a avea`, притяжательные, прилагательные, сравнение |
| 3 | Действие | A1 | четыре группы глаголов, неправильные, возвратные |
| 4 | Где и куда | A1 | предлоги, исчезающий артикль, вопросительные слова |
| 5 | Вчера и завтра | A2 | `perfect compus`, причастия, будущее `o să` |
| 6 | Живая речь | A2 | конъюнктив вместо инфинитива, клитики, `pe`, вежливость |
| 7 | Было и бывало | B1 | `imperfect`, условное наклонение, придаточные с `care`, будущее `voi` |
| 8 | Порог B1 | B1 | косвенная речь, пассив и `se`, герундий, связки аргумента |

У каждой недели своя грамматика, свои словарные темы и живой текст, на котором виден результат. Приложение считает норму рабочего дня (сейчас это около 25–30 минут), показывает дедлайн конкретной датой и **пересчитывает прогноз выхода на B1 по настоящему темпу** — включая пропуски. Отстал — ничего не сгорает: можно нагнать или одной кнопкой сдвинуть дедлайн на сегодня, не теряя прогресс.

## Что заставляет возвращаться

Осознанно **без наказаний**. Ни жизней, ни сгорающей серии, ни «Duo расстроен»: страх потери — плохое топливо, на нём приложение открывают, чтобы откупиться, а не чтобы учиться.

- **Живой текст** — главное. Двенадцать настоящих кусков румынского: записка соседки, вывеска, меню, объявление на вокзале, прогноз в новостях. Приложение честно подсвечивает, сколько слов в них уже узнаётся, и раскрашивает каждое слово по состоянию: знаешь / встречал / новое. Ничего не начисляется «за старание» — счёт растёт только от реально выученного, поэтому через неделю тот же текст светится ярче без единой подкрутки. Это единственное доказательство прогресса, которое невозможно подделать очками.
- **Одна кнопка «Продолжить»** — она всегда знает, что полезнее сделать сейчас (созревшее повторение, следующий урок, сцена, текст), и всегда говорит, что за ней откроется. Обещание вместо угрозы.
- **Явный конец дня.** Норма закрыта — приложение так и пишет: «на сегодня всё». Дальше только если самому хочется.
- **Ритм вместо серии.** Календарь занятий за пять недель: закрашенная клетка значит «в этот день я занимался», пустая не значит ничего. Счётчик «дней с языком» только растёт и не может обнулиться.
- **Комбо** — 3 правильных подряд дают ×2 опыта, 6 → ×3, 9 → ×4.
- **Задания дня**, **20 ачивок** (включая скрытые) и **ранги** от «Новичка» до «Почти румына».

## Что внутри

### Тропа — курс грамматики с нуля до B1

**9 глав, 46 уроков, 424 задания, 114 карточек правил, 9 боссов.**

Курс сделан контрастивно к русскому — упор на то, что для русскоговорящего неочевидно:

- определённый артикль приклеивается **к концу** слова (`casă → casa`);
- прилагательное стоит **после** существительного;
- притяжательное согласуется с **предметом**, а не с владельцем;
- после предлога артикль **пропадает** (`la magazin`, но `cu mașina`);
- перед одушевлённым дополнением ставится **`pe`** — и местоимение при этом удваивается;
- вместо инфинитива используется **`să` + спрягаемый глагол** (`Vreau să merg`);
- вида глагола нет вовсе: «читал» и «прочитал» различаются **выбором времени** (`citeam` против `am citit`);
- а двойное отрицание и отсутствие сдвига времён в косвенной речи, наоборот, работают **как в русском**.

Восемь типов заданий: карточка правила, выбор варианта, сборка фразы из слов, ввод текста, сопоставление пар, аудирование, поиск ошибки в предложении, преобразование формы.

### Тренажёр: 20 повторов на каждую теорию

Правило без повторов не превращается в навык, поэтому у **каждого из 37 уроков** есть свой блок практики на **20 заданий** — отдельным заходом после теории, а не вперемешку с ней. Приложение предлагает его само: закончил урок — верхняя кнопка становится «Закрепить».

Двадцать примеров на сорок уроков руками не пишут, да и незачем: грамматическое упражнение — это функция от правила и слова. В `src/data/drills/` лежат только строки-случаи (10 на тему, 370 всего), а задания собирает генератор в `src/logic/drills.ts`: одна и та же строка становится и выбором формы среди похожих, и преобразованием, и вводом руками. Это три разных навыка — человек, который уверенно выбирает вариант, очень часто не может ту же форму воспроизвести. Итого **740 сгенерированных заданий** поверх 424 написанных вручную.

**Через время тема возвращается сама.** У грамматики свой SRS, отдельно от слов: тема, которую отработали, всплывает через день, три, неделю — и приходит **короткой версией**, пять заданий вместо двадцати. Тот же материал, но на две минуты. Проваленный блок интервал не двигает: получить «увидимся через месяц» после двадцати ошибок было бы издевательством над смыслом повторения.

В любом задании **по слову можно нажать и увидеть перевод**. Словарь подсказок понимает не только начальные формы: спряжения (`ești`, `mănâncă`, `am fost`), слова с приклеенным артиклем (`casa` → `casă`), клитики и служебные слова, а русские слова ищет ещё и по основе. В заданиях на ввод подсказка даёт перевод только тапнутого слова и никогда не показывает ответ целиком.

### Тест на уровень

Отдельная кнопка на «Тропе» (и в профиле, чтобы перепройти). Идёт главами: пять вопросов на каждую, набранных из заданий самой главы. Сдал главу (4 из 5) — переходим к следующей. Правильность по ходу не показывается: это проверка, а не урок.

Зачтённые главы отмечаются пройденными с пометкой `ТЕСТ`. **Опыт за них не начисляется**, а уже пройденное вручную тест не трогает.

### Словарь по темам

**70 тематических юнитов, 1578 слов и фраз.** Карточки со свайпом, четыре типа упражнений (включая аудирование — слово только звучит), интервальное повторение: освоенные слова показываются всё реже, забытые возвращаются быстро.

### Два режима погружения

**Языковое.** Переключатель, после которого приложение **целиком переходит на румынский**: интерфейс, кнопки, подписи. Переводы прячутся под тап — их надо запросить осознанно. Плюс 10 бытовых сцен с озвучкой, построчным переводом и вопросами **на румынском**.

**Экранное.** Полноэкранный режим Android: скрываются системные часы, иконки уведомлений и панель навигации — на экране остаётся только приложение. Включён по умолчанию. Ничего не блокируется: свайп от края показывает панели как обычно, а Android возвращает их при сворачивании, поэтому режим переустанавливается сам при каждом возврате в приложение (`src/logic/useFullscreen.ts`).

Оба переключателя лежат рядом на вкладке «Погружение» и в настройках профиля.

### Справочник

Иконка ≡ в шапке «Тропы» — 37 тем по разделам: **чтение и звуки**, существительное, глагол, местоимения, предложение, практика. Чтение стоит первым: алфавит, пять особых букв (ă â î ș ț), ловушка `ce/ci` против `che/chi`, слипшиеся гласные, немое конечное «-i», ударение.

## Ощущения от интерфейса

Тёмная тема в духе «стеклянных» игровых оверлеев: почти чёрный фон, один фиолетовый акцент, сдержанная типографика. Всё нажимаемое физически проседает под пальцем и отпружинивает, каждое значимое действие отдаёт в руку вибрацией (`src/logic/haptics.ts` — единая точка, дозировано), новые задания проявляются, а не подменяются рывком, разбор ответа выезжает снизу, опыт на итогах докручивается на глазах.

## Как запустить

```bash
npm install
npm start          # Expo Dev Tools + QR-код
```

Дальше — `npm run android` / `npm run ios` / `npm run web`, либо отсканировать QR-код приложением **Expo Go**.

### Собрать релизный APK

```bash
export ANDROID_HOME=/path/to/android-sdk
npx expo prebuild --platform android --clean
cd android && ./gradlew assembleRelease
# итог: android/app/build/outputs/apk/release/app-release.apk
```

Ключ подписи задаётся в `android/gradle.properties` (`RURO_UPLOAD_STORE_FILE` и рядом). Без них соберётся debug-вариант.

По умолчанию APK получается ~70 МБ: внутрь кладутся библиотеки под четыре архитектуры. Для конкретного телефона хватит одной:

```bash
./gradlew assembleRelease -PreactNativeArchitectures=arm64-v8a -Pexpo.useLegacyPackaging=true
```

## Как расширять

- **Слова** — дописывать в `src/data/units*.ts`; уроки и id пересобираются автоматически.
- **Курс** — новая глава это новый файл `src/data/course/chN.ts`, добавленный в массив в `index.ts`.
- **Живой текст** — новый объект в `src/data/texts.ts`; для каждого слова нужен `gloss`, чтобы тап никогда не молчал.
- **Практика** — новая пачка в `src/data/drills/chN.ts` с id урока: десяти строк хватает на двадцать заданий, остальное делает генератор.
- **План** — недели описаны в `src/data/plan.ts`: главы, темы словаря, тексты и сцены на каждую.

## Ограничения

- Озвучка идёт через системный TTS телефона (`expo-speech`, голос `ro-RO`). Если румынский голос не установлен, звук может не воспроизвестись.
- Прогресс хранится локально, облачной синхронизации нет.
- Иконка и сплэш — из шаблона Expo, файлы в `assets/` можно заменить.
